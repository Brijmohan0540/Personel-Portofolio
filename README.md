# IndiMitr - Premium Spiritual Travel Platform

Next.js 15 production-ready starter for a luxury spiritual stays marketplace.

## Stack
- Next.js 15 + TypeScript
- Tailwind CSS
- Framer Motion + GSAP/Lenis ready
- Supabase integration-ready
- Razorpay/WhatsApp/Maps API placeholders

## Run
```bash
npm install
npm run dev
```

## Pages
Home, Explore, Destination, Property Details, Host Dashboard, About, Contact, Blog, Auth, Checkout, Profile.
